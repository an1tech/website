# an1.tech

Static website for AN1 apps, published with GitHub Pages at https://an1.tech.

- `/sudoku/` – AN1 Sudoku support page (App Store Support URL)
- `/sudoku/privacy-policy/` – AN1 Sudoku privacy policy (App Store Privacy Policy URL)
- `/fifteen/` – AN1 Fifteen support page (App Store Support URL)
- `/fifteen/privacy-policy/` – AN1 Fifteen privacy policy (App Store Privacy Policy URL)

Plain HTML, no build step (`.nojekyll`). The custom domain is set in `CNAME`.
